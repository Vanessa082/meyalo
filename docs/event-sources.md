# Event sources

Where curators look for events, by category. Use it with the console's
**Coverage** view: a highlighted zero (for example Bamenda, agriculture) means
look here first.

Rules for every source:
- Link to the official page; never copy flyers or photos without permission.
- Respect each site's terms and robots rules. No scraping tools.
- Record what you checked with **Record a check** in the console.
- Apply the growth rule: skills, livelihoods, health, opportunity or community.

**Status:**
- **Verified**: a primary or reliable source was seen on the date given.
- **To verify**: a lead from research. Confirm it before relying on it.
